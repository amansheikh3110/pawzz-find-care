Practo for Animals — Product Concept

Kashif Sheikh · Submitted for Pawzz Foundation
01

Product Concept

Who: pet parents in urban India (primary), street-animal rescuers and feeders (secondary), with vets, clinics, ambulances, NGOs and boarding facilities as the supply side.

First problem: in a crisis — an injured stray, a sick pet after hours — there is no reliable way to find a nearby, verified vet, ambulance or rescuer. Information is scattered across Google, Instagram and WhatsApp groups. This is the highest-intent, most frequent pain point, so discovery-in-a-crisis comes before routine browsing or booking.

Five MVP features:

  1. Location-based directory of vets, ambulances, NGOs, rescuers and boarding facilities, filterable by distance and open-now status.
  2. Verified provider profiles — timings, services offered, one-tap call/WhatsApp.
  3. Emergency SOS mode — nearest 24×7 vet, ambulance or rescuer, ranked by ETA and verification.
  4. Pet health profile — basic pet details plus vaccination and visit history.
  5. AI document upload — a photo of a prescription or report becomes a structured timeline entry with reminders.

03

AI & Automation

Medical-document extraction Processes: a photo of a prescription, vaccination card or lab report. Automates: manually re-typing medical history — the model extracts diagnosis, medicines and next-due dates and writes them straight into the pet's timeline, with reminders.
Symptom triage & routing Processes: a free-text symptom description plus species/age. Automates: deciding urgent vs. routine and routing to the right provider type, instead of a blind directory search.
Directory enrichment Processes: unstructured listings pulled from Google, Instagram and WhatsApp Business. Automates: structuring, de-duplicating and flagging inconsistent entries — the manual ops work of building the directory.
Rescue-story & campaign copy Processes: a rescuer's raw notes and photos. Automates: drafting a publishable rescue story or fundraiser post.

Own concepts: the emergency-first framing, ranking SOS results by ETA + verification (not ads), and using document-extraction to build a longitudinal pet health record are mine. The base "searchable directory" pattern is inspired by Practo/JustDial-style platforms, as named in the brief.

04

Technology

StackNext.js (mobile-responsive web) on Vercel; Supabase (Postgres + PostGIS, auth, file storage); Claude API for document extraction and triage chat. IntegrationsGoogle Maps/Places (location, geocoding) · WhatsApp Business API (contact, reminders) · Claude API (vision + text) · Razorpay (donations) · Firebase Cloud Messaging (push reminders). ConnectionsClient → API layer → Postgres/PostGIS (providers, pets, records) + object storage (uploaded documents). The AI layer sits beside the API for extraction/triage; Maps, WhatsApp and Razorpay are called from the API layer as needed.
05

MVP Thinking — 30 Days

Build

Directory + geo-search, provider profiles, SOS flow, manual pet profile, and the AI document-upload feature — launched Gurgaon-only with 30–50 manually onboarded, verified listings.

Leave out

Booking & payments, native mobile apps, self-serve provider onboarding, reviews/ratings, AI chat triage (needs tuning), multi-city expansion.
